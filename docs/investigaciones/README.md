# Investigaciones Tecnicas

Esta carpeta concentra investigacion aplicada y postmortems tecnicos.

## Archivos

- `INVESTIGACION_ROTACION_TILES_MAPLIBRE.md`: investigacion extensa sobre rotacion + tiles y limitaciones de motor.
- `DEBUG_FIXES_2026-04.md`: registro de fixes aplicados (lint/tests/build) y decisiones tomadas.

## Convencion

- Prefijo recomendado: `DEBUG_FIXES_YYYY-MM.md` para fixes.
- Cada entrada debe incluir: problema, causa raiz, cambio aplicado, validacion.
- Si un documento pasa a ser guia de uso, moverlo a `docs/` raiz.
